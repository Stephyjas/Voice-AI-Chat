# 🎙️ VoxAI - Text to Voice Chatbot

VoxAI is a simple and interactive **Text-to-Voice Chatbot** that allows users to enter text messages and listen to responses using voice synthesis.

## ✨ Features

* 💬 Interactive chatbot interface
* 🔊 Text-to-speech conversion
* ⌨️ Send messages using Enter key
* 🎨 Modern dark-themed UI
* 🌌 Attractive purple and teal design
* 🌐 Runs directly in the browser
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Browser Speech Synthesis API
* Google Colab

## 🚀 How to Run

1. Open the project in Google Colab.
2. Run the code cell.
3. Enter a message in the chatbot.
4. Click the send button.
5. Click **🔊 Speak** to hear the response.

## 🎯 Project Purpose

The project demonstrates how **text input can be converted into spoken audio** using browser-based speech synthesis technology.
